# Реперторій — гомеопатичні препарати за симптомами

Сайт: **https://ix21027.github.io/homeo-repertory/** — дві мовні версії: українська (`#/ua/…`, автоматичний переклад
Google Translate з постобробкою) і російська (`#/ru/…`, оригінал). Перемикач UA/RU у шапці зберігає поточну сторінку
та вибрані рубрики реперторію.

Статичний сайт (працює на GitHub Pages без збірки на сервері) з трьома частинами:

- **Симптоми** — реперторій: додаєте один або кілька симптомів чи хвороб, отримуєте таблицю препаратів.
  Види рубрик:
  - *Клініка* — нозології з розділу «Клиника» Materia Medica Кларка (≈2 500 рубрик; словоформи злито за стемами,
    підрубрики виду «Головная боль при простуде» входять у батьківську «Головная боль» зі ступенем 1; ступінь 2–3,
    якщо хвороба згадана й у тексті опису препарату);
  - *Модальність* і *Причина* — розібрані розділи «Модальности» («Хуже/Лучше: …», 177 рубрик) та «Этиология»
    (35 рубрик); вибираються зі списку «Модальності й причини» під пошуком або з тегів на сторінці препарату.
    Модальності мають два ступені: **2** — клауза стоїть у самому розділі «Модальности»; **1** — фраза
    видобута з речення симптомного розділу (див. «Модальності: дві фази» нижче);
  - *Стаття* — усі препарати зі статті лікувальника; *Рубрика* — рядки виду «_локалізація_ — Graphites, Sepia…»;
  - *Текст* — повнотекстовий пошук по реченнях усіх текстів: усі слова в одному реченні — сильний збіг, в одному
    абзаці — слабкий; розділи «Характеристика», «Тип», «Взаимосвязи» важать менше; сума нормується за обсягом опису
    препарату; синоніми (хуже = ухудшение, страх = боязнь…), виправлення одруків за словником індексу,
    виключення `-слово`; російський стемер Snowball, український стемер і словничок UA→RU (`search-core.js`).
  - Кожній рубриці можна дати вагу ×1–×3, зробити її обов'язковою (!) або виключною (−); таблицю можна сортувати
    за покриттям, балами чи назвою; 2–4 препарати можна відкрити в порівнянні (прапорці в рядках).
- **Препарати** — 341 препарат із «Словаря практической Materia Medica» Дж. Г. Кларка за розділами
  (Характеристика, Психика, Голова, … Модальности, Этиология, Взаимосвязи). Назви препаратів у тексті — посилання.
- **Статті** — 136 статей «Домашнього гомеопатичного лікувальника» за хворобами, 8 статей про квіткові настої
  д-ра Баха, 4 статті про гомеопатію. У кожній статті блоки препаратів прив'язані до сторінок препаратів.

Джерело текстів — архів сайту «Сам себе гомеопат» (homeopat-sam.com), мова оригіналу російська; українська версія
перекладена автоматично (`tools/translate.py`), тож можливі неточності; оригінал завжди доступний за перемикачем RU.

## Структура

```
index.html, app.js, style.css   — сайт (без залежностей, хеш-маршрутизація: #/<lang>/rep, #/<lang>/remedy/<id>, #/<lang>/article/<id>)
search-core.js                  — токенізація, стемери (російський Snowball, спрощений український), словничок UA→RU,
                                  кодування індексу (спільний код Node і браузера)
repertory.js                    — логіка пошуку та реперторизації без DOM (тестується у Node)
content/ru/remedies/*.md        — чистий текст препаратів, оригінал (frontmatter + розділи «## …»)
content/ru/articles/*.md        — чистий текст статей («## підзаголовок», «### Препарат (транслітерація)»)
content/ua/…                    — українська версія тих самих файлів (абзац до абзацу)
data/<lang>/                    — згенеровано з content/<lang>/: catalog.json, index.json, remedies/*.json, articles/*.json
tools/extract.py                — hom.zip → content/ru/*.md (лише стандартна бібліотека Python 3)
tools/translate.py              — content/ru → content/ua (Google Translate через translatepy, кеш tools/translate-cache.json)
tools/build.mjs                 — content/<lang>/*.md → data/<lang>/ (Node ≥ 18); індекс v3: одиниця — речення
tools/modalities.mjs            — категорії модальностей/етіології (регекси + підписи ru/ua), розбір «Взаимосвязи»
sources/wayback/*.html          — 21 стаття лікувальника, якої немає в hom.zip (копії з Wayback Machine, 2020)
tools/report.txt, build-report.txt — звіти екстракції та збірки
tools/uitest/                   — тести: unit.js (пошук у Node), basic.js, features.js, modal2.js (headless-браузер),
                                  run.sh (прогін наборів на локальному сервері)
tools/report-mined-modalities.txt — вибірка 100 видобутих модальностей із ручною оцінкою точності
.github/workflows/build.yml     — CI: збірка data/ і tools/uitest/unit.js на кожен push і PR у main
```

## Формат Markdown

Препарат:

```
---
id: aconitum-napellus
type: remedy
latin: Aconitum napellus
transliteration: Аконитум
common: борец ядовитый
title: Aconitum napellus (Аконитум) — борец ядовитый
source: Джон Генри Кларк. «Словарь Практической Materia Medica в 6-ти томах»
origin: https://homeopat-sam.com/-/a18
sections: Характеристика; Психика; …
---

## Характеристика
абзац…

## Модальности
- **Хуже.** …
```

URL реперторію: `#/<lang>/rep?r=<рубрики через |>&s=<сортування>&c=<препарати для порівняння>`; рубрика —
`<вид><прапорці>:<тіло>`, де вид `n` (Клініка), `m` (модальність, тіло `w.motion`/`b.rest`), `e` (причина, `fright`),
`a` (стаття, id), `l` (рядок), `f` (текст, `<розділ>~<запит>`), прапорці `!` обов'язкова, `-` виключна, `2`/`3` вага.

Стаття: `## Підзаголовок` — тематичний підрозділ, `### Aconitum (Аконитум)` — блок препарату, `_Кёлер_:` — посилання
на автора-джерело. Правити текст можна прямо в `.md` (українську версію — у `content/ua/`, `translate.py` не
перезаписує наявні файли без `--force`); після правок перезбирайте `data/`. Абзаци в `ru` і `ua` мають лишатися
один до одного: український індекс використовує російські стеми вирівняних абзаців.

## Перезбірка

```
python3 tools/extract.py ~/hom.zip --extra ~/homeo/raw_html sources/wayback   # заново витягти тексти (архів + додаткові HTML)
python3 tools/translate.py             # перекласти нові файли content/ru → content/ua (потрібен інтернет)
node tools/build.mjs                   # content/<lang>/*.md → data/<lang>/
python3 -m http.server 8000            # локальний перегляд: http://localhost:8000/
```

## Тести

```
tools/uitest/run.sh            # усі три набори на власному сервері (порт 8765), ~5 хв
node tools/uitest/unit.js      # лише перевірки пошуку: секунди, без сервера і браузера
```

`unit.js` перевіряє пошук і реперторизацію прямо через `repertory.js` і `data/`; `basic.js`
(дві мови, перемикач, сторінки препаратів і статей) і `features.js` (ваги, елімінативні та
виключні рубрики, сортування, порівняння, підстави, перемикач «Статті») ганяють інтерфейс у
headless-Chromium через puppeteer. Набори параметризовані змінними `BASE`, `CHROME`, `SHOTS`,
`PUPPETEER` — подробиці в `tools/uitest/README.md`; той самий набір можна пустити й на живий
сайт: `BASE=https://ix21027.github.io/homeo-repertory/ node tools/uitest/basic.js`.

На кожен push і pull request у `main` GitHub Actions (`.github/workflows/build.yml`) перезбирає
`data/` і проганяє `unit.js`. Браузерні набори в CI не ганяємо — puppeteer там нестабільний.

## Модальності: дві фази

**Фаза 1 — розділ «Модальности».** `parseModalities()` ділить абзаци на клаузи, успадковує напрямок
від заголовка **Хуже.**/**Лучше.**, перевертає його на маркерах усередині клаузи («хуже… облегчается
от…») і зіставляє з таблицею `MOD_CATS` (94 категорії, регекси по російському тексту). Клауза-виняток
(«При прикосновении (за исключением боли в спине)») класифікується по голові, хвіст відкидається.
Покриття — 95,9 % клауз (`tools/build-report.txt`, рядок `modality coverage`).

**Фаза 2 — симптомні розділи.** `mineModalities()` проходить речення всіх розділів препарату, крім
«Модальности», «Этиология», «Взаимосвязи», «Клиника», «Характеристика», «Тип», «Рекомендации» і
вступного блоку, і бере лише ті, де є явний маркер напрямку: `хуже/лучше`, `ухудшение/улучшение`,
`усиливается/усугубляет/обостряет/возобновляется`, `облегчается/ослабевает/уменьшается/смягчает`,
`проходит/прекращается/исчезает/легче`, `не переносит/непереносимость`. Класифікується не все
речення, а **вікно біля маркера**, інакше `motion` ловив би «усилие» з самого маркера, а `heat` —
«жар» із назви симптому:

- *(а) після маркера* — якщо в перших чотирьох словах є прийменник або прислівник часу
  («усиливается **при движении**»); вікно ріжеться на `;`, на дужці, на сполучнику наслідку
  («поэтому», «которая») і на 80 символах;
- *(б) перед маркером* — якщо маркер перехідний («Теплое питье **уменьшает** кашель») або обставину
  винесено вперед («**На свежем воздухе** усиливается головокружение»);
- заперечення («не проходит от кашля») і порівняння («лучше всего», «тем хуже») відкидаються.

Видобуті елементи лежать у `doc.mods` з ознакою `src:'text'` і назвою розділу, у рубриці дають
**ступінь 1**, у підставах показуються реченням із назвою розділу (не більше трьох на рубрику).
Кількість біля рубрики у списку «Модальності й причини» — **лише секційні** препарати, щоб список
лишався мірою того, що автор виніс у модальності явно.

**Точність.** Вибірку зі 100 видобутих клауз оцінено вручну: **92 % правильних** (напрямок і
категорія) — вибірка, критерій і всі вердикти в `tools/report-mined-modalities.txt`. Решта 8 %:
межі слова в наявних регексах категорій (`утр` у «внутрь»), супутній симптом замість обставини,
дієприкметник-означення замість маркера.

## Обмеження

- В архіві hom.zip є 296 із 341 препаратів індексу сайту; решту 45 узято з копій сторінок того ж сайту, збережених
  раніше з Wayback Machine (`tools/extract.py … --extra <теки з HTML>`). Статей лікувальника в архіві 115 із 136;
  відсутню 21 взято з Wayback Machine (`sources/wayback/`).
- Категорії модальностей/етіології визначаються регулярними виразами по російському тексту (покриття ≈96 % і ≈96 %
  фраз, звіт у `tools/build-report.txt`); для української версії категорії переносяться з оригіналу за вирівнюванням
  клауз і речень. Видобуті з тексту модальності (ступінь 1) правильні на 92 % — вони доповнюють таблицю, але не
  замінюють читання опису.
- У кількох наявних регексах категорій є хибні збіги через межі слова: `лун` збігається з «полуночи» (рубрика
  «фазы луны»), `стоян` — із «состояние» (рубрика «стоя»). Виправлення прибрало б з цих рубрик 21 і 11 препаратів
  відповідно, тому його винесено в окрему зміну.
- Препарати, згадані у статтях, але без власної сторінки (Stramonium, Kali phosphoricum тощо), показуються в таблиці
  реперторію з позначкою «без сторінки».
- Український текст — машинний переклад: терміни й узгодження місцями неточні; у розділі «Клініка» частина назв
  хвороб перекладена словничком. Для перевірки завжди є оригінал (RU). Типові пастки Google виправляються в
  `tools/translate.py`: перед перекладом «язык», «стул», «образование» замінюються однозначними словами того ж роду
  (`protect_ru`), після перекладу «веко → повіка», «рожа → бешиха», «виски → скроні», «течение → перебіг»
  правлять правила з узгодженням прикметників (`fix_terms`, застосовуються під час рендеру, тож нове правило не
  потребує повторного перекладу). Знайшли ще одну пастку — додайте правило й запустіть `translate.py --force`.
  Вибіркову перевірку 2 400 абзаців і всіх 2 703 назв рубрик «Клініки» зробили агенти (Haiku) 13.09; за їхніми
  знахідками додано ще ~30 правил: лицо → обличчя (не «особа»), стеснение → стиснення, саднящий → що саднить,
  икры → литки, рожистое → бешихове, возбуждение → збудження, поясничная область → поперекова ділянка,
  истечение → витікання, мерещится → ввижається, область → ділянка, глотка (не «горлянка»), живот → живіт (не
  «тварина»), зев → зів, терміни на -ит (синусит, а не «синусить») тощо; жирні списки латинських назв у статтях
  не перекладаються (Google їх обрізав).
- Довідник не замінює консультацію лікаря.
